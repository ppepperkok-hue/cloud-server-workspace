# 文档中心

本目录是工作区的**单一事实来源（SSOT）**。规则只有一份，不散落、不重复。

## 子目录

| 目录 | 用途 | 何时读 |
| --- | --- | --- |
| `operations/` | 操作规范：上手、约定、安全、密钥 | 每次开工前、违反规则前 |
| `runbooks/` | 操作手册：具体任务的分步执行文档 | 执行某类具体任务前 |
| `inventory/` | 清单：服务器、服务、端口、密钥位置 | 需要知道「东西在哪」时，**唯一来源** |
| `decisions/` | ADR 决策记录 | 需要知道「为什么这么做」时 |
| `postmortems/` | 事故复盘 | 出事故后复盘、学习历史教训时 |

> 立项类文档**不放这里**。每个新项目自成独立仓库，立项四小步（核心价值 → 核心目标 → 功能拆解 → 可执行单元）与汇总清单随项目走；本工作区只保留「这台机器上部署了什么、怎么部署、怎么回滚」的记录。

## 维护规则

- 每个子目录内必有 `README.md` 说明该目录的维护规范。
- 修改规范后，在 `state/CHANGELOG.md` 记录变更原因。
- 禁止在聊天、代码注释里维护「事实」，一律落到这里。
