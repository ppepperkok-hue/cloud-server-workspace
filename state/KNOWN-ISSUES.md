## 维护方式

1. 发现问题 → 加「未解决」表，写清影响与缓解。
2. 缓解措施落地 → 更新「缓解措施」列。
3. 彻底解决 → 移到「已解决」，写解决方式与时间，关联 CHANGELOG 记录。
4. 有历史价值的事故 → 同步写 `docs/postmortems/`。
