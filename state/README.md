# 共享运行状态（state/）

本目录是多个 agent 协作的「共享记忆」，防止信息孤岛的关键。三个文件各司其职：

| 文件 | 作用 | 维护方式 |
| --- | --- | --- |
| `CHANGELOG.md` | 操作日志（谁、何时、做了什么、结果、回滚方式） | **追加式**，只增不改历史 |
| `TASKS.md` | 任务看板（待办/进行中/已完成/阻塞） | 认领前先改状态，完成后更新 |
| `KNOWN-ISSUES.md` | 已知问题与缓解措施 | 解决后标注，不删除 |

## 协作铁律

1. **动手前先读**：读 CHANGELOG 尾部 + TASKS 全表，确认不冲突。
2. **做完必写**：任何操作后，CHANGELOG 追加一条 + TASKS 更新状态。
3. **认领必标**：要做的任务先在 TASKS 标 `进行中(owner=你的名字/agent id)`，避免两个 agent 撞车。
4. **冲突不覆盖**：发现别人的进行中任务或文件改动，先在 TASKS 标注，不要直接覆盖。
5. **交接写清楚**：任务转手用 `templates/handoff.md`，填好放本目录并更新 TASKS owner。
