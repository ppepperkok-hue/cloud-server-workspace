# 模板库（templates/）

文档模板统一放这里，实例内容放各自目录。填模板时复制，不改模板本身。

| 模板 | 用途 | 填好放哪 |
| --- | --- | --- |
| `runbook.md` | 任务分步执行文档 | `docs/runbooks/` |
| `operation-record.md` | 单次操作记录（可贴进 CHANGELOG） | `state/CHANGELOG.md` |
| `postmortem.md` | 事故复盘 | `docs/postmortems/` |
| `handoff.md` | 任务交接说明 | `state/` |

## 规则

- 模板是**空壳**，不往里填真实内容。
- 新增模板时在这里登记。
